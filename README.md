# bee-desi

Artisanal Raw Single-Flora Honey & Indigenous Apiculture E-Commerce Platform.

## Features
- Single-flora pure raw honey collections
- Geographical traceability and laboratory purity reports
- Curated bundles, gift boxes, and wellness tonics
- Seamless checkout with Razorpay integration
- Order tracking and email confirmations

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
